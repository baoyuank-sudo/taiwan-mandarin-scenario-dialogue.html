# 🇹🇼 Taiwan Mandarin Scenario Dialogue

一個專為外籍學習者設計的台灣華語情境對話練習平台。

## ✨ Features

- 🇹🇼 台灣慣用華語
- 📚 TOCFL A1–B1 情境
- 💬 情境式中文對話
- 🔊 中文語音朗讀
- 💡 實用語法解析
- 🧠 心智圖與相關生詞
- 📖 生詞：中文、拼音、英文與用法
- ✍️ 課後理解問答
- 📱 Responsive Web Design
- 🚫 不需要後端或資料庫
- 🌐 可直接部署到 GitHub Pages

## 🎯 Learning Levels

- TOCFL A1–A2：基礎生活情境
- TOCFL A2–B1：實用生活、職場與社交情境

## 🗂️ Scenarios

包含以下類型：

- 🏢 宿舍日常生活
- 🏫 校園課堂與學業
- 🍔 校園社交與休閒
- 🛒 日常生活與購物
- 🍽️ 飲食與餐廳
- 🚗 交通與旅遊
- 💼 職場與商務
- 🏥 醫療與公共服務
- 🎉 社交與娛樂

## 🔊 Text-to-Speech

網站使用瀏覽器內建的 Web Speech API
進行中文語音朗讀。

語音語言設定為：

`zh-TW`
